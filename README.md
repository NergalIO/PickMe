# PickMe

Игра в жанре tower defense с элементами коллекционирования персонажей и автоматического боя.

## Описание проекта

PickMe - это мобильная игра, где игрок собирает коллекцию персонажей, развивает их и использует в автоматических боях в Башне. Проект разрабатывается на Unity с использованием Universal Render Pipeline (URP).

## Основные системы

### 🎭 Система персонажей
- **Призыв персонажей**: Получение новых героев за билеты (3 персонажа за 1 билет)
- **Коллекция**: Хранение и просмотр всех полученных персонажей
- **Классы**: Воин, Разведчик, Танк, Маг
- **Способности**: Автоматическая активация при выполнении условий
- **Статусы**: Отслеживание жизни персонажей (жив/повержен)

### ⚔️ Боевая система
- **Башня**: PvE контент с этажами и наградами
- **Автономный бой**: Персонажи действуют самостоятельно по ИИ
- **Поведение по классам**: 
  - Танки агрессируют врагов на себя
  - Воины атакуют заагренных врагов или ближайших
  - Разведчики и Маги атакуют незаагренных врагов
- **Способности**: Система автоматической активации способностей

### 🏙️ Система города
- **Главный экран**: Лобби, объединяющее все системы
- **Здания**:
  - Дом (Хранилище персонажей)
  - Зал призыва
  - Башня
  - Портал экспедиций (SOON)
  - Здание мерджа (SOON)
- **Строительство**: Система постройки зданий

## Технические требования

- **Unity**: 2022.3 LTS или новее
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Платформа**: Мобильные устройства (iOS/Android)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd PickMe
```

2. Откройте проект в Unity Hub:
   - Выберите версию Unity 2022.3 LTS или новее
   - Откройте папку проекта

3. Unity автоматически импортирует все зависимости

4. Откройте сцену `Assets/Scenes/City.unity` (будет создана позже)

## Конфигурация

Все игровые конфиги загружаются из Google Sheets:
- [Конфигурационная таблица](https://docs.google.com/spreadsheets/d/1pCmLahOx5tny2wRkne1TufABv47aUoGQOvCtC0v34yA/edit?usp=sharing)

Листы конфигурации:
- `summon` - параметры призыва и классов персонажей
- `ability_list` - способности персонажей
- `tower_floors` - этажи башни и награды
- `enemy` - параметры врагов

## Параметры персонажа

Каждый персонаж имеет следующие параметры:
- `id` - уникальный идентификатор
- `class_tag` - класс (warrior, scout, tank, mage)
- `base_hp` - базовое здоровье
- `base_atk` - базовая атака
- `atk_range` - радиус атаки
- `atk_speed` - скорость атаки
- `move_speed` - скорость передвижения
- `ability_chance` - вероятность получения способности
- `has_ability` - наличие способности
- `is_dead` - статус (жив/повержен)
- `ch_name` - имя персонажа (рандомится из списка)

## Способности

Способности активируются автоматически при выполнении условий:
- `ability_id` - ID способности
- `ability_name` - название
- `activate` - условие активации (СТАТ [знак] ЗНАЧЕНИЕ)
- `ability_effect` - эффект (СТАТ [знак] МНОЖИТЕЛЬ)
- `ability_duration` - время действия
- `ability_cooldown` - время перезарядки
