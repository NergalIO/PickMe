# PickMe

Мобильная игра в жанре tower defense с элементами коллекционирования персонажей и автоматического боя.

## Описание проекта

PickMe - это игра для мобильных устройств, где игрок собирает коллекцию персонажей, развивает их и использует в автоматических боях в Башне. Проект разрабатывается на Unity с использованием Universal Render Pipeline (URP) и новой Input System.

## Реализованные системы

### ✅ Архитектура проекта
- **PersistentSingleton** - базовый класс для всех менеджеров с паттерном Singleton
- **Структура проекта** - организованная структура папок для всех систем
- **Input System** - интеграция новой Input System Unity 6 для мобильных устройств

### ✅ Система менеджеров
- **GameManager** - управление состояниями игры (City, Combat, Summon, Collection)
- **CharacterManager** - управление коллекцией персонажей, отрядом и хранилищем
- **CombatManager** - управление боевой системой, победа/поражение
- **CityManager** - управление зданиями и навигацией по городу
- **ConfigManager** - загрузка конфигов из Google Sheets (CSV)
- **SaveManager** - сохранение и загрузка прогресса игрока (JSON)
- **InputController** - управление вводом через Input System с поддержкой Touch жестов

### ✅ Система персонажей
- **CharacterData** - модель данных персонажа со всеми параметрами
- **SummonManager** - система призыва персонажей за билеты
- **SummonLogic** - логика рандомизации персонажей по классам
- **SummonController** - контроллер экрана зала призыва
- **CollectionManager** - менеджер коллекции персонажей
- **CollectionUI** - UI коллекции персонажей
- **CharacterCardUI** - UI карточки персонажа с отображением параметров

### ✅ Боевая система
- **TowerManager** - управление этажами башни и наградами
- **TowerFloor** - компонент этажа башни
- **TowerUI** - UI выбора этажа
- **TowerRewards** - система выдачи наград
- **EnemyController** - контроллер врага в бою
- **EnemyAI** - ИИ врага (выбор цели, атака)
- **Goblin** - тип врага "Гоблин"
- **CharacterCombatController** - контроллер персонажа в бою
- **CharacterAI** - базовый ИИ персонажа
- **TankAI** - ИИ танка (агрессия врагов на себя)
- **WarriorAI** - ИИ воина (приоритет заагренных врагов)
- **ScoutAI** - ИИ разведчика (атака незаагренных врагов)
- **MageAI** - ИИ мага
- **AbilitySystem** - система способностей
- **Ability** - базовый класс способности
- **BloodSacrifice** - способность "Кровавая жертва" для Воина

### ✅ Система города
- **Building** - базовый класс здания
- **House** - Дом (Хранилище персонажей)
- **SummonHall** - Зал призыва
- **TowerBuilding** - Башня
- **PortalBuilding** - Портал экспедиций (SOON)
- **MergeBuilding** - Здание мерджа (SOON)
- **ConstructionManager** - менеджер строительства зданий
- **ConstructionUI** - UI строительства
- **BuildingPlace** - площадка под строительство

### ✅ Модели данных
- **CharacterData** - данные персонажа
- **EnemyData** - данные врага
- **AbilityData** - данные способности
- **TowerFloorData** - данные этажа башни
- **BuildingData** - данные здания

### ✅ UI системы
- **UIPanel** - базовый класс для UI панелей
- **MenuBase** - базовый класс для меню с поддержкой Input System
- **UIController** - контроллер UI с управлением стеком меню
- **CombatResultUI** - UI результатов боя (победа/поражение)
- **HPBarUI** - полоска здоровья для персонажей и врагов

### ✅ Input System
- **InputController** - Singleton контроллер ввода
- Поддержка Enhanced Touch для мобильных устройств
- Обработка жестов: Tap, Swipe
- События Touch: Start, Move, End
- Интеграция с Player и UI Action Maps

## Технические требования

- **Unity**: 2022.3 LTS или новее
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Input System**: Unity Input System Package

## Конфигурация

Все игровые конфиги загружаются из Google Sheets:
- [Конфигурационная таблица](https://docs.google.com/spreadsheets/d/1pCmLahOx5tny2wRkne1TufABv47aUoGQOvCtC0v34yA/edit?usp=sharing)

Листы конфигурации:
- `summon` - параметры призыва и классов персонажей
- `ability_list` - способности персонажей
- `tower_floors` - этажи башни и награды
- `enemy` - параметры врагов

## Параметры персонажа

Каждый персонаж имеет следующие параметры:
- `id` - уникальный идентификатор
- `class_tag` - класс (warrior, scout, tank, mage)
- `base_hp` - базовое здоровье
- `base_atk` - базовая атака
- `atk_range` - радиус атаки
- `atk_speed` - скорость атаки
- `move_speed` - скорость передвижения
- `ability_chance` - вероятность получения способности
- `has_ability` - наличие способности
- `is_dead` - статус (жив/повержен)
- `ch_name` - имя персонажа (рандомится из списка)

## Способности

Способности активируются автоматически при выполнении условий:
- `ability_id` - ID способности
- `ability_name` - название
- `activate` - условие активации (СТАТ [знак] ЗНАЧЕНИЕ)
- `ability_effect` - эффект (СТАТ [знак] МНОЖИТЕЛЬ)
- `ability_duration` - время действия
- `ability_cooldown` - время перезарядки

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd PickMe
```

2. Откройте проект в Unity Hub:
   - Выберите версию Unity 2022.3 LTS или новее
   - Откройте папку проекта

3. Unity автоматически импортирует все зависимости

4. Убедитесь, что Input System Package установлен

5. Откройте сцену `Assets/Scenes/City.unity` (будет создана позже)
