# Боевая система

## Структура папок

### Tower/
Логика башни:
- TowerManager.cs - Менеджер башни
- TowerFloor.cs - Данные этажа
- TowerUI.cs - UI выбора этажа
- TowerRewards.cs - Система наград

### Enemies/
Противники:
- EnemyController.cs - Контроллер врага
- EnemyAI.cs - ИИ врага (выбор цели, атака)
- EnemyData.cs - Данные врага
- Goblin.cs - Тип врага "Гоблин"

### Abilities/
Способности:
- AbilitySystem.cs - Система способностей
- Ability.cs - Базовый класс способности
- BloodSacrifice.cs - Способность "Кровавая жертва" (Воин)

### AI/
ИИ персонажей:
- CharacterAI.cs - Базовый ИИ персонажа
- TankAI.cs - ИИ танка (агрессия на себя)
- WarriorAI.cs - ИИ воина (приоритеты атаки)
- ScoutAI.cs - ИИ разведчика
- MageAI.cs - ИИ мага

## Логика боя
- Автономное поведение персонажей
- Выбор целей по классу
- Автоматическая активация способностей
- Определение победы/поражения
- Награды за победу
