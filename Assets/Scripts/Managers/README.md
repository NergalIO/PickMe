# Менеджеры игровых систем

## Основные менеджеры

### GameManager.cs
Главный менеджер игры:
- Управление состоянием игры
- Переходы между сценами
- Инициализация систем

### CharacterManager.cs
Менеджер персонажей:
- Хранение коллекции персонажей
- Управление отрядом
- Проверка лимита хранилища (Дом)

### CombatManager.cs
Менеджер боя:
- Управление боевой сценой
- Определение победы/поражения
- Координация действий персонажей и врагов

### CityManager.cs
Менеджер города:
- Управление зданиями
- Переходы между системами
- Состояние города

### ConfigManager.cs
Менеджер конфигов:
- Загрузка данных из Google Sheets
- Парсинг CSV/JSON
- Кэширование конфигов

### SaveManager.cs
Менеджер сохранений:
- Сохранение прогресса игрока
- Загрузка сохранений
- Управление данными игрока
