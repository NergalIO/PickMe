# Система города

## Структура папок

### Buildings/
Здания:
- Building.cs - Базовый класс здания
- House.cs - Дом (Хранилище персонажей)
- SummonHall.cs - Зал призыва
- TowerBuilding.cs - Башня
- PortalBuilding.cs - Портал экспедиций
- MergeBuilding.cs - Здание мерджа
- BuildingData.cs - Данные здания

### Construction/
Строительство:
- ConstructionManager.cs - Менеджер строительства
- ConstructionUI.cs - UI строительства
- BuildingPlace.cs - Площадка под строительство

## Здания
1. **Дом** - Хранилище персонажей (построен изначально)
2. **Зал призыва** - Призыв персонажей (построен изначально)
3. **Башня** - PvE контент (построена изначально)
4. **Портал экспедиций** - Без UI, "SOON" (построен изначально)
5. **Здание мерджа** - Без UI, "SOON" (построен изначально)

## Логика
- Тап по зданию открывает UI
- Если здание не построено → UI строительства
- Проверка условий и ресурсов
- Замена площадки на здание после постройки
